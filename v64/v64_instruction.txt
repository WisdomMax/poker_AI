PHASE 2. Seed 303 붕괴 원인 추적
- Seed 303의 10k, 20k, 35k, 50k 체크포인트를 사용.
- 모든 체크포인트에서 동일한 고정 관측 상태 집합을 입력.
- 검증 항목:
  * Q-Network 행동별 Q값
  * Average Policy 행동별 확률
  * RL Best Response 행동 vs 실제 Average Policy 행동
  * 행동별 합법 여부, TD Error 분포, Reward Scale, Gradient Norm, Target Network 업데이트
  * Reservoir Buffer 행동별 저장 개수 및 Reservoir 교체 알고리즘
  * NFSP Anticipatory Mode 적용 여부
- 특히 SL 버퍼 전체가 올인 라벨로 채워졌다는 주장을 실제 저장 샘플 개수로 검증.
- Reservoir Sampling인지 FIFO Buffer인지 구분.
- NFSP의 Average Policy가 실제로 어떤 분포를 학습했는지 확인.

PHASE 3. 보상 스케일링 검증
- 학습 보상의 원래 단위 확인 (칩 단위 vs BB 단위 vs 이미 정규화된 값).
- 100BB에서 모든 플레이어가 100BB씩 올인할 경우 한 플레이어의 순수익 범위는 [-100, +400]BB.
- 선형 스케일링 우선 적용 (BB 단위: raw_reward_bb / 100, 칩 단위: raw_reward_chips / 10000).
- 보상 합계가 제로섬을 유지하는지 테스트.
- [-2, +2] 클리핑은 기본 설정에 도입하지 않음 (게임 보상 왜곡 주의).

PHASE 4. 정책 붕괴 방지 Ablation
- Seed 303의 붕괴 전 체크포인트(Ep 10k)에서 동일 조건으로 재훈련.
- 독립 비교군:
  * A. 기존 알고리즘 그대로
  * B. 선형 보상 정규화만 적용 (normalized_reward = raw / 100)
  * C. 선형 보상 정규화 + Gradient Clipping (max_norm = 1.0 등)
  * D. Double DQN / Target 안정화 실험
  * E. 정책 엔트로피 정규화 실험
- 각 변경 사항의 영향을 개별적으로 검증 (동시 복합 도입 금지).
- Reservoir Buffer 임의 재가중이나 올인 비율 강제 제한 금지. 고정 올인 페널티 비추천.
