PHASE 0. 모델 및 입력 호환성 검증
20BB 정보 상태는 149차원, 50BB는 161차원으로 보고됐다.
다음 사항을 확인한다:
- 기존 149개 입력 특성의 이름, 순서 및 의미
- 새로 추가된 12개 입력 특성의 정의
- 첫 번째 Linear Layer에서 실제 가중치가 복사된 위치
- Q-Network와 Average Policy Network의 전이 방식
- 새 입력 차원의 초기화 방식
- 전이한 각 체크포인트의 완전한 SHA256
- 전이 전후 동일한 게임 상태에서 공통 특성의 해석 일치 여부

PHASE 1. AI 리그 구성
기존 저장 체크포인트로 다음 모델 풀을 구성한다:
- 50BB Scratch 50k: 5개 시드 (42, 101, 202, 303, 404)
- 50BB Warm Start 50k: 5개 시드 (42, 101, 202, 303, 404)
- 50BB 이전 체크포인트 (20k/30k)
- RuleBased 및 Random: 외부 강도 비교용
모든 모델은 평가 중 가중치를 고정한다.
평가 정책은 Stochastic Average Policy를 사용하고 행동 샘플링 난수를 명시적으로 고정한다.

PHASE 2. 5인 AI 리그전
A. 특정 모델 대 다수 상대 (1 Hero vs 4 Opponents):
   - Scratch 50k vs Warm Start 50k 4명
   - Warm Start 50k vs Scratch 50k 4명
B. 혼합 모델 5인 테이블 (Scratch & Warm Start 혼합)
C. 기존 RuleBased 재평가 (비교 기준선)

PHASE 3. 독립 평가 조건
- 최소 5개 학습 시드
- 사전 고정 신규 평가 스케줄 3개 이상
- 스케줄당 1,500핸드 이상 (총 4,500핸드)
- 5개 좌석 균등 회전, 제로섬 및 칩 원장 검증

PHASE 4 & 5. 전략적 강건성 및 통계 검정
- Scratch 상대 bb/100 vs Warm Start 상대 bb/100
- Fold facing bet, Check vs Call, Pot Raise, All-in 세부 빈도
- Paired t-test (Warm Start vs Scratch)
