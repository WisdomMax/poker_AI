응! ㅋㅋㅋ 😆 신경망(Neural Network)도 코드로 만드는 거야.

🧠 1. 신경망은 어떻게 만드냐?

보통 파이썬의 PyTorch라는 라이브러리로 만들어.

예를 들어 우리 포커 AI에서 사용하는 128 × 128 신경망은 이런 구조야.

Python
import torch
import torch.nn as nn

class PokerAI(nn.Module):
    def __init__(self, input_size):
        super().__init__()

        self.network = nn.Sequential(
            nn.Linear(input_size, 128),
            nn.ReLU(),
            nn.Linear(128, 128),
            nn.ReLU(),
            nn.Linear(128, 4)
        )

    def forward(self, x):
        return self.network(x)

이 코드만으로 은닉층 2개, 각 128개 뉴런을 가진 신경망이 만들어져.

마지막 출력 4개는 우리 포커 AI의 행동에 대응해.

Fold
Check / Call
Pot Raise
All-in
2. 그런데 진짜 중요한 건 학습이야

코드로 신경망을 만들었다고 바로 포커를 잘하는 건 아니야.

처음에는 신경망의 가중치가 무작위로 설정돼 있어.

그 상태에서 AI가 자기 자신과 포커를 반복하면서 학습하는 거지.

자기 대국 → 결과 관측 → 가중치 수정 → 다시 자기 대국

이 과정을 수만 번 반복하면서 전략이 변화하는 거야.

3. 우리가 만든 NFSP는 신경망이 두 개야
신경망	역할
Q-Network	각 행동의 예상 가치를 학습
Average Policy Network	자기 대국에서 축적된 행동 패턴을 학습

두 신경망이 서로 다른 역할을 수행하면서 포커 전략을 발전시키는 구조야.

그래서 이론적으로는 사람이 가르치지 않은 전략도 스스로 발견할 수 있어.
