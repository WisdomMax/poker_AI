# ChatGPT 결과 자동 전송 규칙

사용자가 **"결과보내"**, **"결과 보내"**, **"결과 전송해"**, **"챗지피티에 보내"** 등과 유사한 요청을 할 경우:

1. 즉시 터미널에서 다음 명령을 실행한다:
   ```bash
   python3 /Volumes/NVME/7.AI_vibe_coding/hangame/send_result.py
   ```
2. 이 스크립트는 가장 최근에 작성된 보고서 아티팩트(`*_report.md`)를 자동으로 탐색하여 전체 내용을 ChatGPT 데스크톱 앱의 활성 대화창("홀덤 기계적 전략")으로 붙여넣고 즉시 전송(Enter)한다.
3. 전송된 파일명과 결과를 사용자에게 간결히 확인 보고한다.
