========================================
PHASE 1. AlwaysFold -50 원인 규명
========================================

현재 게임은:

5 Players
SB = 0.5BB
BB = 1.0BB

로 보고되어 있다.

앤티가 없다면
모든 핸드에 참여하지 않고
블라인드만 잃는 플레이어의
5핸드당 블라인드 비용은 1.5BB다.

정상적인 균등 좌석 회전에서
100핸드당 총 블라인드 비용은:

(0.5 + 1.0) / 5 * 100
= 30BB

이다.

따라서 항상 블라인드를 잃는
All-Folder의 수익률은
-30bb/100이 된다.

무료 체크나 미경쟁 팟을
가져가는 상황이 있다면
실제 손실은 이보다 적을 수 있다.

그런데 V5.3에서는
정확히 -50bb/100이 보고되었다.

이는 Hero가 매 핸드
SB를 내는 상황과 일치한다.

다음을 직접 검증한다.

1. 실제 Hero Seat ID
2. 실제 Dealer/Button Position
3. Small Blind Position
4. Big Blind Position
5. Hero가 낸 SB 총액
6. Hero가 낸 BB 총액
7. Hero가 낸 Ante
8. Hero가 자발적으로 투자한 칩
9. Hero가 회수한 칩
10. Hero의 최종 Net Return

최소 500핸드를 평가한다.

핸드별로 다음 로그를 남긴다.

hand_id
hero_agent_id
hero_physical_seat
dealer_seat
sb_seat
bb_seat
hero_blind_paid
hero_voluntary_contribution
hero_terminal_return

5개 포지션에 Hero가
각각 100회씩 배치됐는지 확인한다.

매 핸드 Hero가
같은 SB 또는 BB 자리에 있었다면
평가 오류로 판정한다.

좌석 회전은 단순한 문자열 변경이나
Agent ID 리네이밍이 아니라
실제 블라인드 부담 및
게임 행동 순서에서 검증한다.

정상 회전이 확인되기 전까지
기존 수익률을 최종 성능으로 인정하지 않는다.


========================================
PHASE 2. bb/100 계산 검증
========================================

현재와 과거 게임에서
단위 변환을 통일한다.

Net Chips
Big Blinds
BB per Hand
bb/100

을 명확히 구분한다.

공식:

Net BB = Net Chips / BB Chip Value

bb/100 = Net BB / Hands * 100

10BB와 20BB에서
Big Blind 자체의 칩 가치가
변경됐는지 확인한다.

예:

BB = 100 chips

10BB Stack = 1000 chips
20BB Stack = 2000 chips

스택 증가와 블라인드 증가를
혼동하지 않는다.

제로섬 칩 보존을 검증한다.

매 핸드:

Sum(Player Terminal Net Chips) = 0

레이크 없는 환경에서는
반드시 성립해야 한다.

20BB 게임에서 Hero의
핸드당 Terminal Return은
정상적인 동일 스택 5인 게임 기준
-20BB ~ +80BB 범위를 벗어나면 안 된다.

올인, 사이드팟,
동점 분할팟에서도 검사한다.

단위 변환을
서로 독립적인 두 함수로 계산해
결과가 일치하는지 확인한다.


========================================
PHASE 3. 기존 V5.3 수익률 재평가
========================================

기존 체크포인트를 그대로 사용한다.

대상:

NFSP-DQN 2,000 eps

NFSP-DQN 5,000 eps

NFSP-DQN 10,000 eps

학습 시드:

42
101
202
303
404

좌석 회전과 bb/100 검증을
통과한 평가 엔진에서
모든 체크포인트를 다시 평가한다.

기존 RuleBased 봇을 사용하되
상대 봇 구성과 동작을 고정한다.

동일한 카드 시퀀스,
상대 RNG,
동일 좌석 회전 스케줄을 적용한다.

평가 중에는
신경망 가중치를 갱신하지 않는다.

모든 모델은 동일한 평가 방식으로
Stochastic Average Policy를 사용한다.

별도 Argmax 결과를 원한다면
진단 항목으로만 추가한다.

각 학습 시드별로:

2k bb/100
5k bb/100
10k bb/100

을 출력한다.

그리고:

Gain_2k_to_10k =
EV_10k - EV_2k

을 계산한다.

5개 독립 학습 시드에 대해:

Mean Gain
Standard Deviation
Student-t 95% CI
Paired t-test
Effect Size

를 산출한다.

게임 판수를
독립 학습 모델 수로 취급하지 않는다.

평균 개선폭이 +31.1bb/100이라는
기존 결과를 반드시 재검증한다.

5개 시드 중
몇 개에서 실제 개선됐는지도 보고한다.

========================================
PHASE 6. 카드별 Regret 재평가
========================================

장기 학습에서
99의 Regret은 개선됐지만
AA의 Regret이 악화된 시드가 있다.

예:

Seed 404:

AA Regret
2k = 0.00 BB
10k = 1.08 BB

99 Regret
2k = 1.42 BB
10k = 0.20 BB

Seed 101:

AA Regret
2k = 0.80 BB
10k = 4.76 BB

99 Regret
2k = 1.26 BB
10k = 0.08 BB

이 현상을 분석한다.

학습이 한 카드의 전략을
개선하는 동안 다른 카드의
전략을 악화시키고 있는가?

각 체크포인트에서:

AA
KK
QQ
JJ
TT
99

를 검사한다.

상황:

Unopened
Facing Raise
Facing All-in
Multiway Pot

다음 지표를 출력한다.

Policy Probability
Action EV
Policy Expected EV
Best Action EV
Policy Regret

카드별 Regret 평균은
상황 발생 빈도를 반영한
가중 평균과
상황별 개별 평균을 구분한다.

카드별 TVD가 증가해도
Regret이 악화된다면
전략적으로 개선됐다고
판정하지 않는다.

상대 레인지는
실제 의사결정과 일관되게
조건부 샘플링한다.

상대 비공개 카드가
정책 입력에 누출되지 않도록 한다.
