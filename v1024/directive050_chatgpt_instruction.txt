DIRECTIVE 050: ALPHASTAR LEAGUE INTEGRATION
5인 독립 PPO × PFSP 실학습 루프 연결 및 1,000핸드 제한 파일럿

Repository: https://github.com/WisdomMax/poker_AI
기준 커밋: 01d87c1
목표: 기존 5인 PPO 자가대국에 동결 과거 정책 리그와 동적 상대 선택을 통합하고, 실제 학습이 정상 작동함을 검증한다.

0. 공식 승인 범위
DIRECTIVE 049-C의 Holm 보정과 PFSP 반응성 구현은 인정한다.
다만 다음 항목은 미완료 상태다.
- 111/113건 차이의 실제 원인 검증
- 동일 덱 실험의 올바른 250쌍 통계
- 5개 Main Learner의 공평한 참여
- PFSP 상대 선택과 실제 대국 결과의 피드백 연결
- PPO Gradient 업데이트 및 Optimizer 복원
- 동결 상대가 포함된 리그의 실학습 검증
본 지침의 최대 신규 학습 규모는 총 1,000핸드다. 10,000핸드 본학습은 금지한다.

1. 111건과 113건 차이 재검증
기존 047과 049-A의 콜 분류 차이는 다음과 같다.
- 047에서만 콜 분류: Hand 215, 260, 325, 429, 465, 496 (6건)
- 049-A에서만 콜 분류: Hand 69, 119, 274, 399 (4건)
즉, 6건이 빠지고 4건이 추가되어 순차이 2건이 발생했다.
이를 일괄적으로 99.8% 경계 오차라고 설명하지 않는다.
원본과 재현 실행의 다음 항목을 비교한다.
- 초기 홀카드 및 전체 카드 덱
- 후속 찬스 노드 RNG 상태
- Native Action 시퀀스
- 행동 전후 스택
- Action Mask
- 정책 로짓 및 최종 행동
- 올인 이벤트
- 핸드 최종 손익
특히 Hand 465와 496에서는 원본의 직접 올인이 재현에서 폴드로 바뀌었다.
두 실행의 최초 행동 분기 지점을 찾아 원인을 증명한다.

2. 동일 덱 통계 수정
049-C의 동일 덱 실험은 250쌍이다.
각 시드에서 두 구성을 짝지은 250개 통계 단위로 분석한다.
기존 원시 결과의 재계산 기준:
- 평균: -108.08 BB/100
- 95% CI: 약 [-376.76, +160.60]
- p-value: 약 0.4290
테스트에서 이 값과 일치하는지 검증한다.
추가로 정책별 실제 손익과 좌석 정보를 원시 기록에 보존한다.

3. PFSP 샘플러 공식 통일
현재 구현은 평균 손익 기반 소프트맥스다.
보고서의 패배율 거듭제곱 공식과 실제 구현이 다르므로 명칭과 수식을 일치시킨다.
다음 두 방법을 명확하게 구분한다.
- Method A: Uniform Historical Sampling (과거 체크포인트를 균등 선택하는 대조군)
- Method B: PFSP / Performance-Based Sampling (관측된 상대별 성적에 따라 상대 선택 확률을 갱신하는 실험군)
표본이 적은 상대에게 한두 번 크게 패배했다는 이유만으로 선택 확률이 과도하게 집중되지 않도록 다음을 검증한다:
- 최소 표본 수
- 통계적 불확실성
- 가중치 상한 및 탐색 비율
- 전적 갱신 주기
- 과거 전략 재등장 시 선택 변화
- 최악의 상대에게만 과적합되는지 여부
5인 게임에서 Hero의 전체 손익을 개별 상대 각각에게 동일하게 귀속하지 않는다.
상대별 성적 추정은 고정된 나머지 좌석과 균형 잡힌 평가 구성을 사용하거나, 다인 구성에 맞는 별도 추정 방법을 명시한다.

4. 5명 Main Learner 공평한 경험 보장
현재 049-C 드라이런은 A, B, C 세 명만 학습자 좌석에 배치했다.
다음 두 모드를 지원한다:
- MODE 1: Full Main Self-Play (A, B, C, D, E 전원 학습형 에이전트, 다섯 정책 모두 경험 수집 및 PPO 업데이트)
- MODE 2: Mixed Historical League (Main Learner와 Frozen 과거 정책이 혼합 참가, 학습자 좌석을 A~E에 균형 있게 순환 배정, Frozen 좌석은 경험 수집 및 Gradient 업데이트 없음)
Mixed Mode에서 다섯 명 모두 매 핸드 학습했다고 보고하지 않는다.
충분한 실행 구간에서 다섯 Main Learner의 참여 횟수는 동일하도록 스케줄링한다.

5. 실제 PPO 실학습 통합
각 Main Learner에 대해 반드시 구현·검증한다:
- 독립 신경망, 독립 Optimizer, 독립 Rollout Buffer
- 실제 행동 당시 Normalized Observation, Legal Action Mask, Old Log Probability, Value Estimate, Reward / Advantage, PPO Clipped Objective, Gradient Update, KL / Entropy / Clip Fraction, 파라미터 변화 및 NaN 검사
학습자가 실제로 게임에 참가한 경험만 학습에 사용한다.
Frozen 모델은 추론만 수행하며 Optimizer와 Gradient 업데이트를 받지 않는다.
학습 체크포인트에는 Model, Optimizer, RNG, 진행 핸드 수 및 리그 샘플러 상태를 포함한다.
기존 7,000h 모델에는 Optimizer 상태가 없으므로, 새 Optimizer 시작이라는 사실을 기록한다.

6. 제한된 실행 검증
- Phase A: 100~200핸드 통합 스모크
  - 다섯 학습자 전원 실제 참여
  - 다섯 정책 모두 실제 Gradient 업데이트
  - Frozen 정책 파라미터 불변
  - PFSP 상대 선택 이벤트 기록
  - 상대 전적 업데이트 및 선택 확률 변화
  - 법적 행동 위반, NaN, 제로섬 오류 0건
  - 학습 체크포인트 저장·복구 성공
- Phase B: 최대 총 1,000핸드 파일럿
  - Phase A를 통과한 경우에만 진행
  - Full Main Self-Play 기준군 vs PFSP Mixed League 실험군 vs Uniform Mixed League 대조군
  - CPU 평균 사용률 70% 이하 유지
  - 본 파일럿은 실력 향상 확증이 아니라 통합 시스템 검증을 목적으로 함.

7. 독립 홀드아웃 평가

- 통계적 유의성이 부족하면 PERFORMANCE_NOT_YET_PROVEN으로 명시
