1. 7,000h 체크포인트 실제 제출

현재 7,000h 결과를 사후에 정확한 연속 학습이었다고 수정해서는 안 된다.

3. HandLedgerTracker 최종 정리

현재 was_allin_called()에는 실제 callers 목록이 비어 있을 때 살아 있는 상대 수로 결과를 추정하는 로직이 남아 있다.

팟베팅으로 내 스택이 소진

복수 플레이어가 콜

쇼트스택 올인과 리레이즈

실제 사이드팟 발생

모두 폴드한 무콜 올인

모든 콜 이벤트에는 해당 플레이어의 실제 행동과 투자 금액을 연결한다.

사이드팟을 검증했다고 주장하려면 메인팟·사이드팟의 기여 금액 및 정산까지 검산해야 한다.

hero_allin=false → opp_called=false는 기본 전제이며, 그 자체로 콜 추적 정확성을 증명하지 못한다.

4. 올인 EV 지표 통일

기존 -44.28BB와 이번 -8.82BB는 측정 대상이 다르므로 직접 비교하지 않는다.

직접 올인한 핸드의 최종 순손익

직접 올인 후 콜당한 핸드의 순손익

팟베팅으로 전액 투자한 핸드의 순손익

콜당하지 않은 올인의 순손익

표본 수와 신뢰구간을 함께 제공한다.

학습에 직접 참여하지 않은 독립 체크포인트 또는 검증된 합리적 정책 집단과 대전한다.

동일한 게임 조건, 블라인드, 스택, 레이크 가정, 평가 시드 및 정책 행동 모드를 사용한다.

이전에 강했던 전략이 다시 등장했을 때도 방어 가능한가?

다섯 정책이 서로 다른 약점을 갖는가?

새로운 정책 변화가 단순한 전략 순환인지, 전반적인 경쟁력 개선인지 구별 가능한가?

## 6. AlphaStar형 진화형 자가대국 리그 아키텍처 설계안

단순 최신 모델 간 대결의 전략 망각과 순환 문제를 극복하기 위해 검증된 **AlphaStar Fictitious Self-Play (PFSP)** 구조를 채택합니다:


[Main Learner Pool] (현재 학습 중인 5개 독립 PPO 에이전트 A~E)
         │
         ├── 50% 확률: Main Learner 상호 자가대국 (최신 메타 적응)
         │
         ├── 35% 확률: [Frozen Historical Pool] (2,000h ~ 6,000h 동결 아카이브)
         │              - PFSP(Prioritized Fictitious Self-Play) 기반 샘플링
         │              - 과거 자신이 패배했던 세대 모델을 우선 소환하여 복수 학습
         │              - 과거 공격형(팟/올인) 봇에 대한 방어 전략 망각 방지
         │
         └── 15% 확률: [Exploiter / Diversity Pool] (고정 규칙 봇 및 특화 봇)
                        - FlawlessTwoPairCatcherBot, Top20 ChenBot
                        - 특정 극단 전략(올인/스몰볼) 대응력 상시 유지


### 리그 운영 규칙
1. **동결 정책(Frozen Policies)**: Historical Pool에 등록된 모델은 일체 가중치를 업데이트하지 않으며 순수 환경 상대(Opponent)로만 참여합니다.
2. **공평한 학습 기회**: 5개 Main 에이전트는 동일한 Rollout 버퍼 크기와 옵티마이저 스텝을 유지합니다.
3. **체크포인트 승격 조건**: 리그 평가에서 이전 세대 대비 승률 55% 이상 및 평균 손익 +50 BB/100 달성 시에만 Historical Pool의 우선 상대로 등록합니다.

## 3. [코드 구현 확인] & [원시 데이터로 검증] Task 3: PFSP 동적 반응성 검증

### 3.1 AlphaStar PFSP 반응 함수
승률 W(opp) = wins / matches에 대해 패배율 L(opp) = 1 - W(opp)을 기준으로 가중치 산출:
- P(opp) = (1 - floor) * (L(opp)^tau / sum(L(j)^tau)) + floor / |K|
- 파라미터: tau = 10.0, floor = 0.1

### 3.2 3단계 상태 전이 검증 결과
1. **State 0 (초기 상태, 경기 전):**
   - 모든 상대 가중치 균등:
     - Agent_A_2000h: 0.2500
     - Agent_B_2000h: 0.2500
     - Agent_C_2000h: 0.2500
     - Agent_D_2000h: 0.2500

2. **State 1 (Agent C에게 패배, Agent B에게 승리):**
   - Agent C 가중치 급증, Agent B 가중치 급감 (약점 집중 공략):
     - Agent_A_2000h: 0.1166
     - Agent_B_2000h: 0.0331
     - Agent_C_2000h: 0.7337
     - Agent_D_2000h: 0.1166
   - **검증:** C의 가중치가 **0.2500 -> 0.7337**로 급상승하여 가장 어려운 상대를 집중 소환함.

3. **State 2 (역전: Hero가 학습하여 Agent C에게 승리):**
   - Agent C 가중치 급감, 아직 검증되지 않은 A, D 가중치 상승:
     - Agent_A_2000h: 0.4035
     - Agent_B_2000h: 0.0719
     - Agent_C_2000h: 0.1211
     - Agent_D_2000h: 0.4035
   - **검증:** C의 가중치가 **0.7337 -> 0.1211**로 하락하고 A/D가 **0.4035**로 상승.
