## 3. 다음 공식 지침: DIRECTIVE 057

이번에는 무조건 학습을 막는 대신, **조건부 16,000테이블 핸드 연구를 승인**하겠습니다.

다만 057의 목적은 단순한 체크포인트 추가가 아닙니다. 기존 고정 상대 풀과 동적으로 확장하는 리그를 직접 비교해, 새로운 상대를 만나면서 학습하는 방식이 일반화 성능을 개선하는지 확인해야 합니다.

**목표:** 동적 체크포인트 리그가 고정 상대 풀보다 일반화 성능을 개선하는지 실제 학습 및 독립 평가로 검증한다.

## TASK 1. 최종 평가 엔진 수정

1. Frozen 2k 평가에서 Agent A~E 전원이 상대 풀에 실제로 등장하도록 수정한다.
2. Frozen 2k, Frozen 7k, 혼합 과거 체크포인트 풀을 각각 평가할 수 있게 한다.
3. 상대 구성과 좌석을 균형 있게 회전하고, 모델군별 상대 출현 횟수를 기록한다.
4. 각 `(평가 시드, 히어로, 좌석, 상대 구성)`에 독립적인 카드 RNG를 사용한다. 정책별 행동 수가 이후 대국의 카드 시퀀스에 영향을 주지 않아야 한다.
5. 행동별 Fold/Call/Raise/All-in 원시 집계를 저장하고 보고서 수치와 자동 대조한다.
6. 056 보고서의 행동 분포 불일치를 정정한다.
7. PPO 로그와 체크포인트, 실행 상태의 전체 동일성을 비교하는 중단·복원 테스트를 강화한다. 비트 일치와 수치 허용오차 일치를 구분한다.

기존 모델과 결과 파일은 변경하지 않는다.

## TASK 2. Dynamic League 구현

기존 Frozen 2k+7k 모델 풀을 기본으로 사용한다.

두 가지 상대 풀 체계를 구현한다.

**Static League**
- 시작 시 지정한 상대 풀을 훈련 종료까지 유지
- Uniform 또는 PFSP 방식으로 상대 선택

**Dynamic League**
- 기존 Frozen 2k+7k 모델을 유지
- 학습 중 500핸드 단위로 과거 학습자 정책을 동결 스냅샷으로 보존
- 보존된 과거 정책을 상대 풀에 단계적으로 추가
- 상대별 학습자 관점 손익, 선택 확률, 선택 횟수 기록
- 최신 정책과 과거 스냅샷의 동시 변경을 금지
- 특정 상대만 과도하게 선택되는 현상을 방지할 최소 탐색 확률 적용

스냅샷은 해시와 생성 시점을 기록하고 재현 가능해야 한다.

Dynamic League에서 각 훈련군이 자체 생성한 스냅샷은 서로 다를 수 있으므로, 그 결과를 순수한 PFSP 샘플러 효과와 동일시하지 않는다. 알고리즘 전체의 효과로 구분하여 해석한다.

## TASK 3. 조건부 16,000테이블 핸드 학습

TASK 1~2의 무결성 테스트 통과 후 시행한다.

| 실험군 | 훈련 시드 | 군당 학습 |
|---|---|---|
| Uniform Static | 2개 신규 시드 | 2,000h × 2 |
| PFSP Static | 동일 시드 | 2,000h × 2 |
| Uniform Dynamic | 동일 시드 | 2,000h × 2 |
| PFSP Dynamic | 동일 시드 | 2,000h × 2 |

**총 16,000테이블 핸드.**

모든 군은 동일한 초기 7k 모델, PPO 설정, 카드 시드 계획 및 좌석 회전 규칙을 사용한다.

- 500h, 1k, 1.5k, 2k 체크포인트 저장
- 첫 500h에서 CPU·PPO·중단복원 카나리 수행
- 각 단계에서 KL, Entropy, Value Loss, Gradient Norm, 행동 변화 기록
- 1,000h 이후에도 지정된 운영 안정성 기준을 만족해야 나머지 진행
- 16,000h를 초과하는 추가 학습은 금지

CPU 제한은 프로세스 누적 CPU 시간 / Wall Time으로 평균 70% 이하를 유지한다.

## TASK 4. 정책 퇴화 방지 및 성능 검증

다음 두 요소를 구분해서 검증한다.

**운영 안정성**
- NaN/Inf 발생 여부
- KL 급증
- 엔트로피 붕괴
- Value Loss 비정상 확대
- 올인 행동 급증
- 체크포인트 재개 실패

**게임 실력 변화**
- 새로운 상대에 대한 BB/100
- 500h → 1k → 1.5k → 2k 성능 변화
- Baseline 7k 대비 대응표본 차이
- Static 대비 Dynamic의 성능 차이
- PFSP 대비 Uniform의 성능 차이
- 에이전트별·좌석별 성능 분산
- 모델 간 직접 교차 대전

056의 PPO Value Loss는 일부 업데이트에서 4만 이상 기록됐다. 손실 수치만으로 실패라고 판단하지 말고, 타깃 보상 규모와 Value Prediction 오차를 함께 분석한다.

하이퍼파라미터를 한꺼번에 변경하지 않는다. 정책 학습이 정상적으로 진행되는지 먼저 확인한다.

## 4. 감독관 최종 연구 판단

056의 가장 큰 성과는 **AI가 강해졌다는 것이 아니라, 학습 환경의 신뢰성이 전보다 높아졌다는 것**입니다.

이제 같은 운영 결함을 반복해서 고치는 단계에서 벗어나, AI의 실제 전략 학습 효과를 분리할 수 있는 실험으로 넘어가야 합니다.

제가 057에서 가장 중요하게 볼 것은 세 가지입니다. **동적 리그가 도움이 되는가, 학습량 증가가 실력 증가로 이어지는가, 새로운 강한 상대에게도 성능을 유지하는가.**

이 세 가지가 긍정적으로 재현된다면 다음 단계에서 수만 핸드 규모의 연속 강화학습을 승인할 근거가 생깁니다.
