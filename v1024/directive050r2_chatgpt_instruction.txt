DIRECTIVE 050-R2: PRODUCTION INTEGRITY RECOVERY
기준 커밋: e7aa810

목표
050-R은 부분적으로 개선됐지만 최종 감사에 불합격했다.
기존 5인 PPO × PFSP 구조를 유지하며, 보고서용 예제 코드가 아닌 실제 운영 학습 및 평가 코드를 수정한다.
신규 10,000핸드 본학습은 금지한다. 학습 재개 무결성을 위한 최대 100핸드 테스트만 허용한다.

P0-1. 평가 모델 자동 대체 금지
050-R 평가 코드의 다음 로직을 즉시 제거한다.
if not os.path.exists(m_path): m_path = ...7000h.pt
평가 대상 체크포인트가 없으면 즉시 FAIL 처리한다.
- 7,000h Baseline 5개
- 050 Full Main 파일럿 5개
- 050 PFSP 파일럿 5개
총 15개 모델의 실제 경로, SHA256, 로드 결과를 제출한다.
파일이 없으면 누락을 인정하고 해당 비교를 무효로 처리한다.
원래 050 모델의 학습 결과를 재생성 없이 복원할 수 없으면 그 사실을 보고한다.

P0-2. 진짜 독립 홀드아웃 평가
기존 Hero Seat 0 고정을 제거한다.
5개 Hero를 좌석 0~4에 균등 배치하고 동일한 동결 상대 풀을 사용한다.
서로 다른 정책 평가에 동일한 사전 생성 덱을 제공하여 카드 배분을 통제한다.
- 모델별·좌석별 BB/100
- Baseline 대비 대응표본 차이
- 95% 신뢰구간
- 실제 올인 발생 및 손익
- 원시 핸드별 JSONL
모든 모델의 파일 ID와 SHA256을 결과에 포함한다.

P0-3. 10개 핸드 원본 비교 재현
현재 050-R은 원인 설명을 하드코딩하고 7,000h 모델만 사용해 재생한다.
이를 원본 047 및 049의 실제 모델·좌석·상대 구성으로 교체한다.
각 논쟁 핸드에서 두 실행을 동시에 비교하여 다음을 출력한다.
- 최초로 달라지는 행동 번호
- 양쪽 Observation과 Action Mask
- 선택 로짓과 행동 ID
- 네이티브 베팅 금액
- 행동 전후 스택
- 실제 올인 판정
재생만 했다는 사실과 최초 분기 원인을 검증했다는 주장을 구분한다.
재현할 수 없는 사건은 UNRESOLVED로 표기한다.

P0-4. 실제 학습 체크포인트 통합
임시 더미 신경망 테스트가 아닌 050의 실제 IndependentPPOAgent 및 리그 학습 코드에 완전 체크포인트 시스템을 통합한다.
포함 필수:
- Model State
- Adam Optimizer State
- PyTorch / NumPy / Python RNG State
- 진행 핸드 및 업데이트 수
- Rollout Buffer 상태
- PFSP Sampler History / Selection State
- 좌석 배정 및 학습 스케줄 상태
검증 방법:
동일 초기 상태에서 50핸드를 연속 실행한 결과와, 25핸드 후 저장·종료·복원하여 25핸드를 추가 실행한 결과를 비교한다.
행동 시퀀스, 가중치, 옵티마이저 모멘텀, 샘플러 상태가 일치하는지 확인한다.
단순 torch.allclose()를 비트 단위 복원 증거라고 부르지 않는다.

P0-5. PFSP 학습 통합 수리
현재 다인 포커의 Hero 손익을 개별 Frozen 상대에게 단순 귀속하는 전적 갱신을 수정한다.
상대별 통제 평가 또는 타당한 다인 상대 추정 방식을 사용한다.
Uniform Historical Sampling을 별도 대조군으로 구현하되, 이번 단계에서는 추가 대량 학습하지 않는다.
후속 본학습에서는 Full Main, Uniform, PFSP를 동일한 시작 조건과 비교 가능한 학습 경험량으로 비교할 수 있게 설계한다.

P0-6. 실제 검증 결과 제출
제출 항목:
- 모든 수정 코드 및 GitHub 커밋
- 15개 체크포인트 경로·SHA256 확인표
- 실제 원시 홀드아웃 JSONL
- 논쟁 10핸드 최초 분기점 증거
- 운영 학습 체크포인트의 중단·복원 일치 테스트
- PFSP 전적 추정 방법과 Uniform 대조군 구현
- 테스트 실행 명령 및 실제 PASS/FAIL 결과

통과 조건은 보고서 문구가 아니라 운영 코드와 재현 가능한 원시 증거다.
050-R2 통과 후 DIRECTIVE 051의 통제된 10,000핸드 학습을 심사한다.
