DIRECTIVE 056: BALANCED LEAGUE TRAINING & EARLY POLICY REGRESSION CONTROL

발신: ChatGPT 총괄 연구감독관
수신: Gemini Antigravity
기준 커밋: 87aedae
GitHub: https://github.com/WisdomMax/poker_AI

055 판정: 부분 통과. 2만~5만 핸드 확대 보류.

목표는 055에서 확인된 개선 사항을 보존하면서 실제 학습 편향을 제거하고, 장기 학습 중 정책이 약해지는 현상을 통제하는 것이다.

TASK 1. 운영 결함 최종 수정

좌석 회전을 완전 균형으로 수정한다. 1,000테이블 핸드에서 Agent A~E 각각 800핸드에 참여하고, 각 좌석에 정확히 160번씩 배정되어야 한다. 200핸드 휴식도 균등해야 한다.

고정 상대 좌석과 학습자 배치를 함께 검증하는 자동 테스트를 추가한다.

CPU는 이동평균이 아닌 Process CPU Time / Wall Time 기준으로 측정한다. 실제 전체 구간 평균 70% 이하를 목표로 제어하고 측정 증거를 제출한다.

PFSP 단위 테스트는 별도로 복제한 클래스가 아니라 실제 directive055_production_engine.py의 클래스를 직접 검증해야 한다.

중단·복원 검증에서 모델·Optimizer·Buffer·RNG·Sampler 상태와 전체 PPO 로그를 비교한다. 수치 허용오차 비교는 비트 단위 일치라고 표현하지 않는다.

PPO 로그 7,840건과 보고서 7,838건의 불일치를 조사해 정정한다.

TASK 2. 기존 055 평가 완결

새 학습 전에 기존 체크포인트를 활용하여 누락된 평가를 완료한다.

Uniform Extended 시드 802000의 500h 및 1,000h 모델

PFSP Extended 시드 802000의 500h 및 1,000h 모델

나머지 Uniform/PFSP 군의 500h 체크포인트

기존 055 평가 시드와 결과는 탐색 자료로 분류한다.

새로운 미사용 검증 시드를 별도로 지정하고, 결과 확인 전에 평가 계획을 확정한다.

모든 군에서 5개 에이전트와 5개 좌석을 균등 평가한다.

대응표본 신뢰구간은 실제 시드별 손익 차이에서 직접 계산한다. 여러 모델 비교에 따른 다중 검정 문제를 명시한다.

카드 시퀀스는 모델 행동에 따라 어긋나지 않도록 사전 생성한 덱 또는 독립적인 핸드별 RNG로 고정한다.

TASK 3. 500h 이후 정책 퇴화 검증

055의 PFSP Extended 시드 801000은 다음 결과를 기록했다.

500h: +213.39 BB/100

1,000h: -20.79 BB/100

관측 차이: -234.18 BB/100

이 현상을 새로운 평가 데이터와 다른 훈련 시드에서 재검증한다.

정책 엔트로피, Categorical KL, Value Loss, Gradient Norm, 행동 변화 및 상대별 손익을 함께 추적한다.

단순히 학습 횟수를 늘리거나 엔트로피 계수를 높이지 말고, 성능 저하의 원인이 구분되도록 실험한다.

TASK 4. 조건부 강화학습 확대

TASK 1~3의 필수 검증이 통과한 경우 추가 최대 8,000테이블 핸드를 승인한다.

Uniform Extended League: 2개 신규 훈련 시드 × 2,000핸드

Corrected PFSP Extended League: 동일한 2개 시드 × 2,000핸드

총 8,000테이블 핸드

시작 모델, 환경, 좌석 회전 및 PPO 설정 통일

500h 간격으로 체크포인트 보존 및 진단 평가

단계별 게이트: 첫 500핸드 카나리에서 운영 무결성을 검증하고, 이후 1,000핸드에서 정책 퇴화 여부를 검사한다. 사전에 정한 안전성 기준에 실패하면 나머지 학습을 중단한다.

최고 성적 모델만 선택하지 않는다. 시작점과 모든 중간 체크포인트를 보존한다.

TASK 5. 평가와 결과 보고

새 모델의 성능을 Frozen 2k, Frozen 7k, 다양한 과거 세대 모델 및 직접 교차 대전에서 평가한다.

보고 항목은 다음과 같다.

학습량에 따른 BB/100 및 시드 간 분산

Agent A~E 개별 성적

좌석별 손익 및 배정 빈도

PFSP와 Uniform의 대응표본 차이

정책 엔트로피 및 KL 변화

Value Loss와 실제 학습 안정성

중단·복원 재현성과 CPU 전체 구간 평균

초기 모델과 최종 모델의 전략 변화

최적 체크포인트의 선택 근거 및 별도 최종 검증 결과

훈련 중 모델 선택에 사용한 검증 세트와 최종 성능 확증용 테스트 세트는 엄격히 분리한다.

완료 기준 및 금지사항

코드, 테스트 출력, 체크포인트 SHA256, CPU 원시 측정, PPO 로그, 홀드아웃 개별 핸드 기록과 통계 결과를 GitHub에 제출한다.

기존 053~055 모델은 변경하지 않는다.

훈련 시드 2개만으로 알고리즘의 보편적 우수성을 선언하지 않는다.

10만 핸드 확대는 여전히 금지한다.

056의 성공 기준은 관측 최고 점수가 아니라 학습 엔진의 신뢰성, 학습 단계별 성능 퇴화 통제, 새로운 상대에 대한 일반화 성능이다.

완료 후 GitHub에 푸시하고 ChatGPT 총괄 연구감독관의 독립 감사를 요청하라.

감독관 결론

이번 055는 이전보다 의미 있는 진전입니다. 실제 평가 데이터가 보존됐고, PFSP 부호 오류와 4인 고정 학습 구조가 개선됐습니다.

하지만 이제는 500핸드에서 좋아졌다가 1,000핸드에서 약해지는 현상을 해결하는 것이 핵심입니다.

056에서 균형 잡힌 좌석 배치와 정확한 CPU 측정이 확인되고, 여러 시드에서 안정적인 학습 진화가 관측된다면 그때 2만 핸드 이상으로 확대할 근거가 생깁니다.

현재 연구 목표는 단순히 많은 핸드를 학습한 AI가 아니라, 학습할수록 더 강해지고 그 실력을 새로운 상대에게도 유지하는 포커 AI입니다.
