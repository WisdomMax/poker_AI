작업 디렉터리: v58/

PHASE 3. 52장 풀 덱 환경 구축
- 5 Players
- 52 Cards (13 Ranks x 4 Suits)
- 50BB (Stack: 5,000 chips, Blinds: 50 / 100)
- 2 Betting Rounds (Preflop + Flop)
- 4 Actions: Fold, Check/Call, Pot Raise, All-in
- 환경 무결성 검증:
  * 중복 카드 0회
  * 칩 보존 (Zero-sum)
  * 핸드 랭킹 (스트레이트, 플러시, 풀하우스, 팟 분할) 정확성
  * 칩 반환 범위 (-50BB ~ +200BB)

PHASE 4. 52장 NFSP Smoke Test 및 훈련
- Q-Network: 128 x 128
- Average Policy Network: 128 x 128
- Learning Rate: 1e-4, Batch Size: 64
- 3개 시드 1,000 에피소드 Smoke Test
- 5개 독립 시드 (42, 101, 202, 303, 404) x 10,000 에피소드 훈련
- 체크포인트: 0, 2,000, 5,000, 10,000

PHASE 5. 52장 학습 성능 평가
- 신규 평가 시드 3개 이상 (총 4,500핸드)
- 좌석 균등 회전
- 상대: AlwaysFold, CheckCall, Random, RuleBased
- bb/100, 95% CI, Seed-wise Gain, 액션 빈도, AA/72o 카드별 행동 분석
