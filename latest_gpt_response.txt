# DIRECTIVE 046: SELF-PLAY EVALUATOR FINAL INTEGRITY GATE

GitHub: https://github.com/WisdomMax/poker_AI

## 실행 결정
DIRECTIVE 045 감사 결과 일부 구현 개선은 인정한다.
하지만 중대한 평가기 결함이 발견되어 추가 5,000~10,000핸드 학습은 보류한다.
이번 단계는 새 학습 없이 평가기 결함 수정 및 재현성 검증만 수행한다.

---

## 1. 카드 배분 순서 긴급 수정
045의 `robust_parse_cards(st)` 호출이 카드 배분 이전에 실행되어 원시 JSONL 2,500건 전부에서 홀카드가 `["2c", "2c"]`로 기록됐다.
다음을 구현한다:
- `advance_chance_nodes()`로 홀카드 배분 완료 후 파싱
- 모든 플레이어의 홀카드 총 10장 중복 검사
- 홀카드와 공개 보드 간 중복 검사
- 카드 문자열을 0~51 정수로 변환하는 함수 검증
- 검사 실패 시 게임 평가 즉시 중단
- 잘못된 홀카드로 평가된 DIRECTIVE 045 캐처 결과 무효 처리
- 카드 배분 전 파서를 호출하는 회귀 테스트는 반드시 실패해야 한다.

---

## 2. 원래 0h 모델 정확히 복원
043 원본 초기화 순서를 그대로 재현한다:
1. `torch.manual_seed(seed)`
2. `np.random.seed(seed)`
3. `PPONeuralPlayer` 생성
4. 50k 체크포인트 로드
5. 모델별 노이즈 적용: `noise = torch.randn_like(p) * 0.005 * (agent_id + 1)`
- 별도 구현으로 재작성하지 말고, 043 원본 `IndependentPPOAgent` 초기화 코드를 직접 재사용할 것.
- 0h 정책과 실제 초기화 정책의 모든 파라미터가 비트 단위로 정확히 일치함을 테스트한다.

---

## 3. 캐처 액션 버그 수정
- Action 0 = Fold, Action 1 = Check/Call 규칙을 정밀 적용한다.
- 무료 체크 상황에서 Fold를 Check로 사용하는 코드와 주석을 수정한다.
- 실제 홀카드와 공개 보드를 사용하는 족보 평가기를 검증한다.
- 플랍 5장, 턴 6장, 리버 7장 기준 핸드 평가 단위 테스트를 작성한다.
- 카드를 정상적으로 받아도 강한 플레이어가 되는 것은 아니므로, 현재 캐처를 "휴리스틱 규칙 기반 평가 상대"라고 정확히 명시한다.

---

## 4. 실제 올인 콜 원장 수정
- 단순히 `to_call >= 5000`인 경우만 콜로 인정하지 않고, 올인 이전 투자 금액, 남은 콜 금액, 실제 상대의 Call 액션을 추적한다.
- 올인이 콜당하지 않았다고 분류된 핸드가 -100BB 손실을 기록하는 모순을 원천 차단하고 회귀 테스트를 추가한다.
- 직접 올인과 팟베팅으로 발생한 전액 투자도 각각 분리 추적한다.

---

## 5. 통합 수용 테스트 (5대 회귀 테스트)
다음 다섯 조건을 전부 만족해야 평가를 실행한다:
1. 1,000개 카드 배분 테스트에서 중복·불가능 카드 0건
2. 043 초기화 재현 테스트에서 가중치 완전 일치
3. 무료 체크·폴드 동작 정상
4. 올인 콜 분류와 실제 원장 일치
5. 핸드 손익 및 제로섬 정산 일치

우선 100~200핸드 스모크 테스트를 실행하고, 통과 후 기존 체크포인트로 500핸드 독립 평가를 진행한다.
추가 PPO 학습은 금지한다.
